# pixel-games

Grayscale arcade trio — Space, Tetris, Breakout. WASD · P pause.

## Local

```bash
# from pixel-ambient/
python3 -m http.server 8771
```

Open http://127.0.0.1:8771/games/

## Controls

| Key | Action |
|-----|--------|
| A/D | Left / right |
| W | Shoot / rotate / launch (restart on game over) |
| S | Soft drop (Tetris) |
| P | Pause |

URL: `?g=space|tetris|breakout`
